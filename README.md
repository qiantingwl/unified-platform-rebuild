# 统一账户平台

独立部署的账户、注册、签到、余额、转发、代理和任务控制台。统一程序使用自己的数据库、账户和路由；运行时不调用旧的账户站或管理程序。

- `app/backend/`：主程序、任务、平台适配和独立浏览器执行器。
- `app/web/`：管理控制台。
- `app/compose.yaml`：主程序、任务服务、浏览器执行器、PostgreSQL 四个容器。
- [交付与验收状态](docs/独立发布交付-20261119.md)：真实转发结果、账户去重、注册与任务状态。

从 `app/.env.example` 创建本机专用的 `app/.env`，配置数据库密码、加密密钥、管理员凭证、浏览器执行器令牌及访问策略。应用默认绑定本机端口；按部署环境配置公开访问入口。配置就绪后，在 `app/` 中运行 `docker compose up -d --build`。主程序负责转发，任务服务可单独更新；浏览器执行器和数据库只在内部网络暴露。也可从账户页通过本程序自己的导入入口提交资料，凭证须按平台验证后才能参与调度。

生产配置、数据库、密钥、访问日志与历史审计原始材料都不属于源码仓库。当前源码是候选版本，真实分组验收结果以交付文档为准。
